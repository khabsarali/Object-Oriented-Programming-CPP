# Lab Reviewed

Combined lab folder for Lab 11 and Lab 12. This lab was reviewed and verified as
part of the Lab Tasks 1-14 review.

| File | Topic | OOP Concept |
| --- | --- | --- |
| Task1.cpp | Box length | Friend function accessing a private data member |
| Task2.cpp | Distance addition | Friend function with two objects as parameters |
| Task3.cpp | Bank Account System | Static data member shared by all objects |
| Task4.cpp | Employee System | Static member function called via the class name |
| Task5.cpp | Hospital Staff System | Abstract class, pure virtual function, runtime polymorphism |

Each task is independently executable. Build any task with:

```
g++ Task1.cpp -o Task1.exe
```
